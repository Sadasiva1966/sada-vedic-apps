# Sada Vedic Apps — website

Static glassmorphism site for App Store **Support** and **Privacy Policy** URLs.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home — Sada Vedic Apps intro + app list |
| `apps/sadarogya-sandhyavandanam.html` | Sadarogya Sandhyavandanam |
| `apps/vedic-seva.html` | Vedic Seva |
| `donate.html` | Donate — UPI QR, UPI ID, PayPal (same as app) |
| `support.html` | **Support URL** for App Store |
| `privacy.html` | **Privacy Policy URL** for App Store |

Support email on the site: **kaka027rot2@gmail.com**

## Local preview

```bash
cd website
python3 -m http.server 8080
```

Open http://127.0.0.1:8080/
